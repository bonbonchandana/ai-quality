Flagged episodes

An episode is a run of hours where the real value was much further from the prediction than usual. For each one we checked whether the inputs were complete. If something was missing, it is marked as a data limitation. If everything was there, it is marked as unusual pollution.

    Use your own data

    Upload an hourly CSV, Excel or ZIP file. It needs a time column (Date and Time, year/month/day/hour, or datetime) and at least one pollutant column such as CO, NO2, NOx, C6H6, PM2.5, PM10, SO2 or O3. Any weather columns in the file are used too. The UCI Beijing station files work as they are.

    Data from the UCI Machine Learning Repository. Made with scikit-learn, XGBoost and FastAPI.
